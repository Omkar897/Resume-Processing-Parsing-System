# AI Resume Processing System

AI-powered resume processing system that extracts structured information from PDF resumes and classifies them into IT job categories with 93% accuracy.

## Features
- PDF text extraction and parsing
- Personal information, skills, education, and experience extraction
- ML-based job category classification (9 IT categories)
- 93% classification accuracy
- Production-ready modular architecture

## Quick Start
- pip install -r requirements.txt
- python main.py --test

text

## Tech Stack
- Python, TensorFlow, scikit-learn
- PyMuPDF for PDF processing
- TF-IDF + Neural Network classification
